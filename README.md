# Saksham Gupta - Portfolio

A personal portfolio website showcasing my experience as an Infrastructure & DevOps Engineer.

## About

This site highlights my professional background, including work experience at Thoughtworks and Publicis Sapient, technical skills in cloud platforms and DevOps tools, certifications, and education.

## Technologies Used

- HTML5
- CSS3 / SASS
- JavaScript
- FontAwesome Icons

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/isakshamgupta/Saksham_portfolio.git
   cd Saksham_portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build CSS from SASS:
   ```bash
   npm run build-css
   ```

4. Start a local server:
   ```bash
   npm start
   ```
   Open http://localhost:8000 in your browser.

5. For development, watch SASS changes:
   ```bash
   npm run watch-css
   ```
